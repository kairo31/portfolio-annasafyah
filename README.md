# Portfolio Annasafyah

React + Vite + Tailwind CSS v4 (neo-brutalist / terminal style).

```bash
npm install
npm run dev
```

## Contact form

The contact form submits directly to Formspree. Copy `.env.example` to `.env`,
then replace `your-form-id` with the endpoint from your Formspree dashboard:

```bash
VITE_FORMSPREE_ENDPOINT=https://formspree.io/f/xkjjbllj
```
